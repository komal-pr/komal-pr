### 🔍 [subrecon](https://github.com/komal-pr/subrecon)
> Multi-source subdomain enumeration toolkit with web UI

Modular Python tool that aggregates subdomains from Certificate Transparency logs, Wayback Machine, AlienVault OTX, URLScan.io, and DNS brute-force. Features DNS resolution with wildcard detection, HTTP probing with tech fingerprinting, rich HTML/JSON reports, and a Flask web dashboard with scan history.
